# تطبيق LL3X لـ iPhone

مشروع iOS أصلي صغير يعرض `https://ll3x.com/` داخل `WKWebView`، مع أزرار للصفحة الرئيسية والرجوع والتقدّم والتحديث. تبقى صفحات `ll3x.com` ونطاقاته الفرعية داخل التطبيق؛ أما الروابط الخارجية فتُفتح عبر المتصفح الافتراضي على الجهاز (Safari عادةً). التطبيق يعرض الموقع الحي ويتطلب اتصالًا بالإنترنت، ولا ينسخ محتوى الموقع أو يغيّره.

## إخراج ملف IPA على Mac

1. فك ضغط مجلد المشروع وافتح `LL3X.xcodeproj` باستخدام Xcode.
2. اختر هدف **LL3X** ثم **Signing & Capabilities**، وحدد فريق Apple الخاص بك واترك **Automatically manage signing** مفعّلًا. إذا رفض Xcode المعرّف `com.ll3x.portal` لأنه مستخدم ضمن فريق آخر، غيّره إلى معرّف فريد تملكه.
3. اختر جهاز iPhone أو شغّل التطبيق أولًا على محاكي عبر **Product → Run**.
4. لإخراج IPA لجهازك أو لأجهزة اختبار مسجلة، اختر **Any iOS Device (arm64)** ثم **Product → Archive**. في نافذة **Organizer** اختر **Distribute App**، ثم **Development** أو **Ad Hoc** واتبع خطوات التصدير.

إذا كنت تستخدم توقيعًا يدويًا بدل التوقيع التلقائي، فيلزم أن تكون الشهادة ومفتاحها الخاص المقابل وملف التزويد المناسب مثبتة في إعدادات Apple على الـMac. هذا المشروع لا يرفع التطبيق إلى App Store.

## حدود ما تم التحقق منه

أُعدّت ملفات المصدر ومشروع Xcode وإعداد الأيقونة، لكن لم يُنشأ أو يُختبر IPA: بيئة الإعداد الحالية Linux ولا تحتوي على Xcode أو أدوات Apple أو شهادة توقيع. اختبر التوقيع والتثبيت وفتح الموقع على Mac وiPhone بعد إعداد حسابك.
